# Research archive

This directory records the research and reasoning behind Codex Commons. It is
kept beside the implementation so later contributors can distinguish tested
constraints from attractive but unproven features.

- [Design synthesis](design-synthesis.md): the smallest viable product model,
  activation policy, safety boundary, and pilot criteria.
- [Sources and prior art](sources-and-prior-art.md): the incident prompt,
  literature supplied for the experiment, and related repositories reviewed.

The source list is an audit trail, not an endorsement. Several sources were
preprints supplied during early ideation; claims should be rechecked against
the current versions before publication or formal citation.
