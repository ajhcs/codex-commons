# Typography

## OpenAI Sans boundary

The [OpenAI Design Guidelines](https://openai.com/brand/) list OpenAI Sans in Light, Regular, Medium, Semibold, and Bold, each with italic, plus ligatures, tabular figures, and case-sensitive punctuation.

Access routes through authenticated [brand.openai.com](https://brand.openai.com/). No public redistribution license was found. No binary is stored here. Do not extract it from an app or public-site CSS. Status: **requires-permission** until a human verifies a suitable license.

## Reusable official UI typography

Apps SDK UI instead uses a system sans stack beginning with ui-sans-serif, -apple-system, system-ui, Segoe UI, Noto Sans, Helvetica, and Arial; mono begins with ui-monospace and SF Mono/Menlo.

| Role | Size / line | Weight |
|---|---:|---:|
| headings 5xl, 4xl, 3xl | 72/72, 60/60, 48/48 px | 600 |
| headings 2xl, xl, lg | 36/42, 32/38, 24/28 px | 600 |
| headings md, sm, xs | 20/26, 18/26, 16/24 px | 600 |
| text lg, md, sm | 18/29, 16/24, 14/20 px | 400 |
| text xs, 2xs, 3xs | 12/18, 10/14, 8/12 px | 400 |

Weights are 400, 500, 600, and 700; semibold is the default bold. Source: [Typography.mdx](assets/official/apps-sdk-ui-0.2.2-0f00143/src/Typography.mdx).

Commons should use the system stack, 14 px dense table body, 12 px metadata, and 20–24 px page titles. These role assignments are **Commons choices**, not OpenAI specs. Use tabular figures for timestamps/counts and avoid 8–10 px operational text.
