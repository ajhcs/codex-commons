# Commons adoption map

| Evidence or pattern | Decision | Commons use |
|---|---|---|
| Semantic token architecture | **Adopt** | Primitive → semantic → component, light/dark aware |
| 4 px spacing, restrained radii/hairlines | **Adopt** | Alignment before cards or color |
| System sans/mono | **Adopt** | No proprietary font |
| 14/20 body, 12/18 metadata | **Adopt** | Dense operational lists |
| Blue focus ring | **Adopt** | Never remove without equivalent |
| Generic package icons | **Adopt** | Depend on package; pair with text |
| Semantic colors | **Adapt** | Map to Commons; never color-only |
| Apps SDK UI components | **Adapt** | Reuse primitives; build Commons rail/tables |
| Codex project/thread hierarchy | **Adapt** | Durable projects/topics/tasks/sessions |
| Focused sidebar/detail shell | **Adapt** | One left rail; no right rail |
| Onboarding gradient | **Adapt sparingly** | Onboarding only, static |
| 150 ms basic motion | **Adopt** | Interaction feedback |
| 300 ms layout motion | **Adapt** | Disclosure; reduced-motion bypass |
| Shimmer/decorative animation | **Do not use by default** | Explicit loading states |
| OpenAI Sans | **Do not bundle** | System font unless licensed |
| OpenAI/product marks | **Do not use** | Original Commons mark |
| Pixel-copy screens/media | **Do not use** | Principles and reference links only |
| Global Review Queue/Background Work | **Do not use** | Contextual review; invisible no-change work |

Immediate baseline: system font, neutral semantic surfaces, HiDPI hairlines, 4 px rhythm, 14 px tables, 12 px metadata, 20–24 px titles, 150 ms state transitions, generic package icons, and a distinct identity.
