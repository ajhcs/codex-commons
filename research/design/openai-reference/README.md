# OpenAI and Codex design reference

Research snapshot: **2026-08-09**. This is a rights-aware reference for Codex Commons, not an OpenAI brand kit or permission to use OpenAI trademarks.

## Locally available

- A pinned, unmodified subset of OpenAI's MIT-licensed [Apps SDK UI](https://github.com/openai/apps-sdk-ui), package 0.2.2 at commit [0f00143](https://github.com/openai/apps-sdk-ui/tree/0f00143c7a639906f1621fe58e1b6be7b5bea46d): token CSS, motion primitives, foundation docs, and 35 generic icons.
- [icon-catalog.json](icon-catalog.json): all 755 icons exported by that commit. The full package is referenced rather than duplicated.
- Source-cited visual, typography, icon, motion, component, layout, rights, and [Commons adoption](commons-adoption.md) notes.
- [asset-manifest.json](asset-manifest.json): provenance, rights status, restrictions, and SHA-256 for every local official-source file.

No OpenAI font binaries, wordmarks, Blossom, ChatGPT/Codex marks, or marketing media are copied. OpenAI Sans access is gated and no public redistribution license was found.

## Evidence labels

- **Official/documented**: stated on an official OpenAI page or licensed source.
- **Source measurement**: calculated from pinned official source.
- **Visual inference**: observed in public product media; not an official specification.
- **Commons decision**: our implementation choice.

Apps SDK UI is for ChatGPT apps, not documented as Codex desktop's internal design system. It is the best public reusable OpenAI-authored foundation, not proof of Codex internals.
