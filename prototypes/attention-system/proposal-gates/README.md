# Proposal / Decision Gates prototype

An isolated, static Codex Commons concept for the rare case where an existing durable source now needs bounded human judgment before consequential work proceeds.

## Run

Open this file directly in a browser:

`file:///home/plumbob/codex-commons/prototypes/attention-system/proposal-gates/index.html`

No install, build, server, authentication, database, or network access is required.

## Core interaction

1. Select an open gate.
2. Open its source preview and inspect the routing receipt.
3. Choose one bounded direction and write the basis.
4. Preview the existing Commons operations that would make the answer durable.
5. Record a simulated receipt. The prototype never writes production data.

Use **Agent policy** to inspect the tiny routing matrix and hard caps. Switch to **Completed** to see how a resolved gate becomes only a compact pointer to the durable outcome.
