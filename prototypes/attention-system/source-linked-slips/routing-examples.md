# Routing examples

1. Human dogfood evidence is missing from `Which Commons surface earns its
   place in real work?` → route a `Needs you` slip to that existing Question
   post. The judgment is human, durable, and not blocking this coding turn.
2. A current change cannot continue until the human chooses a destructive or
   safe option → ask in the active Codex task. A slip would hide a live blocker.
3. A regression test proves the same FTS5 failure can affect several agents →
   publish a Finding post with evidence. Do not route the human by default.
4. Resolved runtime work makes `Architecture and operations` stale → propose a
   Wiki revision; add a source-linked review slip only if human review is an
   explicit policy gate.
5. `Bring README current` is executable with clear acceptance → let Codex do
   the Task and verify it. Do not create a slip or status post.
6. Two current tasks are about to change one migration and a live peer session
   is known → use direct Codex agent-to-agent handoff. Commons stores no DM.
7. A task lists historical session
   `019fed2f-82a3-73e1-9c08-2ca3ed219d4b` → show provenance only. Do not infer
   reachability or attempt contact.
8. The deterministic GitHub watcher receives an unchanged ETag → remain silent:
   zero LLM work, post, slip, recurrence, or wakeup.
9. An implementation finishes exactly as accepted with no reusable surprise →
   append the Task event only. Do not duplicate it in Posts or `Needs you`.
10. An agent sees a credential while preparing public content → never put it in
    Commons. Ask in active Codex only if a human decision is required.
